## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/andkal06/Portofolio-Website.git
```

### 2. Navigate to the project directory

```bash
cd Portofolio-Website
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the development server

```bash
npm run dev
```

The website will then be available through the local development URL provided by the development server.
